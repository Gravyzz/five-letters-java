# Пять букв — Wordle на Java

[![Java CI](https://github.com/Gravyzz/five-letters-java/actions/workflows/java-ci.yml/badge.svg)](https://github.com/Gravyzz/five-letters-java/actions/workflows/java-ci.yml)

**Java 25 · Gradle · JUnit 5 · AssertJ · Spotless · Checkstyle**

Учебный проект консольной игры в духе Wordle. Программа загадывает слово из пяти русских букв, а игрок должен угадать его за шесть попыток.

Реализованы все три этапа задания: словарь и игровая сессия, правила проверки попыток, консольный интерфейс и детерминированный режим запуска.

В последней локальной проверке от 10.11.2026 прошли **66 тестов**, без падений и пропусков. Игровые правила отделены от консоли, поэтому проверяются без интерактивного ввода.

## Быстрый старт

```bash
git clone https://github.com/Gravyzz/five-letters-java.git
cd five-letters-java
./gradlew run
```

Требуется JDK 25 или новее. На Windows вместо `./gradlew` используется `gradlew.bat`.

## Правила игры

После каждой принятой попытки программа показывает состояние каждой буквы:

- `✅` — буква находится на правильной позиции;
- `🟡` — буква присутствует в ответе, но находится на другой позиции;
- `❌` — подходящего вхождения буквы в ответе нет.

Допустимая попытка должна состоять ровно из пяти русских букв и находиться в полном словаре игры. Регистр ввода не учитывается. Некорректный ввод выводит сообщение об ошибке и не расходует попытку.

Повторяющиеся буквы обрабатываются в два прохода: сначала отмечаются точные совпадения, затем оставшиеся буквы ответа используются для статуса `🟡`. Каждое вхождение буквы ответа расходуется только один раз.

Партия завершается победой после угадывания слова или поражением после шестой неудачной попытки.

## Консольное меню

В главном меню доступны команды:

```text
1 - Новая игра
2 - Статистика
3 - Игра по сложности
4 - Игра по категории
0 - Выход
```

После завершения партии программа возвращается в главное меню, поэтому можно сыграть несколько партий без перезапуска приложения. Некорректный пункт меню выводит сообщение об ошибке и не завершает программу.

## Дополнительные возможности

- **Уровни сложности.** Для лёгкого, среднего и сложного уровней используются отдельные наборы возможных ответов.
- **Категории.** Можно выбрать категории «Животные», «Еда» или «Природа». Ответ выбирается из выбранной категории, но в качестве попытки принимается любое подходящее слово из полного словаря.
- **Подсказка.** Во время партии можно один раз ввести `?` и узнать первую букву ответа. Подсказка не расходует попытку.
- **Статистика.** В течение одного запуска хранятся количество завершённых партий, побед и поражений.
- **Цветной вывод.** Подсказки, ошибки, победа и поражение выделяются ANSI-цветами.
- **Replay.** Партию можно воспроизвести без открытия меню по известным `seed` и последовательности попыток.

## Запуск

Для сборки требуется JDK 25 или новее. Отдельно устанавливать Gradle не нужно: в проекте используется Gradle Wrapper.

Обычный запуск:

```bash
./gradlew run
```

Детерминированный запуск с фиксированным `seed`:

```bash
./gradlew run --args="--seed 42"
```

Одинаковые `seed` и словарь с одинаковым порядком слов дают одинаковый ответ. `Seed` не является индексом слова: разные значения могут выбрать один и тот же ответ.

Воспроизведение партии по `seed` и списку попыток:

```bash
./gradlew run --args="--replay 42 арбуз озеро"
```

В режиме replay меню не открывается. Попытки последовательно применяются к партии, созданной с переданным `seed`.

## Структура проекта

Основная игровая логика находится в пакете `academy.fiveletters.game`:

- `WordDictionary` проверяет и хранит неизменяемый список слов;
- `DictionaryLoader` загружает основной и дополнительные словари из ресурсов в UTF-8;
- `GameFactory` выбирает ответ с помощью `Random(seed)` и создаёт игровую сессию;
- `GameSession` хранит ответ, лимит и историю попыток, а также статус партии;
- `GameRules` проверяет ввод и применяет допустимую попытку к сессии;
- `LetterMatcher` вычисляет статусы букв с учётом повторяющихся вхождений;
- `GuessResult` хранит нормализованную попытку и статусы её букв;
- `GameStatistics` хранит статистику завершённых партий за текущий запуск;
- `Difficulty` и `WordCategory` связывают варианты меню с дополнительными словарями.

Пакет `academy.fiveletters.console` отвечает за взаимодействие с пользователем:

- `GameConsole` управляет режимами запуска, меню и ходом партии;
- `menu/MenuController` обрабатывает выбор режима и настроек;
- `runner/ConsoleGameRunner` ведёт партию, `runner/ReplayRunner` воспроизводит попытки;
- `output/ResultFormatter` и `output/ConsoleColors` форматируют результат и ANSI-цвета.

Игровая логика не зависит от консольного ввода-вывода и проверяется отдельно.

## Проверка проекта

Запуск всех тестов и статических проверок:

```bash
./gradlew check
```

Автоматическое форматирование и полная проверка перед отправкой:

```bash
./gradlew spotlessApply check
```

Обязательные тесты MR1, MR2 и MR3 находятся в `src/test/java/academy/fiveletters/mandatory`. Дополнительные сценарии игровой модели и бонусных возможностей находятся в пакетах `game` и `bonus`.

## Ограничения

- Поддерживаются слова из пяти русских букв от `а` до `я`, без `ё`.
- Внешние словари, графический интерфейс, сеть и база данных не используются.
- Статистика хранится только до завершения текущего запуска приложения.
- Для отображения цветов терминал должен поддерживать ANSI-последовательности.
