# Проект 1. «5 букв»

Учебный проект консольной игры в духе Wordle: угадывание слова из пяти русских букв за шесть попыток.

## Текущий статус

Реализован MR1: словарь, воспроизводимый выбор ответа и начальное состояние игровой сессии.

Правила попыток и консольная игра пока не реализованы. Команда `run` запускает заглушку. Выбор по seed доступен через `GameFactory.startGame(...)` и проверяется тестами; консольного режима с seed пока нет.

## Структура MR1

Классы находятся в пакете `academy.fiveletters.game`.

- `WordDictionary` проверяет входной список и хранит его неизменяемую копию. Список не должен быть пустым или `null`. Каждое слово должно соответствовать `[а-я]{5}`: пять строчных русских букв без `ё`. Методы `size()` и `getWords()` позволяют прочитать размер и неизменяемое содержимое словаря.
- `DictionaryLoader` читает встроенный ресурс `/dictionary.txt` в UTF-8. Убирает пробельные символы по краям строк, пропускает пустые строки и комментарии, начинающиеся с `#`. Остальные строки передаёт конструктору словаря. Некорректные слова вызывают ошибку, а не отбрасываются молча. Ресурсы закрываются через `try-with-resources`.
- `GameFactory` выбирает слово из словаря и возвращает новую сессию. При каждом вызове создаётся новый `Random(seed)`, который выбирает допустимый индекс слова.
- `GameSession` хранит ответ, лимит попыток, число использованных попыток, историю и статус. Начальное состояние: ноль попыток, пустая история, `IN_PROGRESS`. Конструктор проверяет положительный лимит и наличие ответа длиной пять символов. История возвращается в виде неизменяемой копии.
- `GameStatus` содержит `IN_PROGRESS`, `WIN` и `LOSE`. Переходы состояний будут реализованы в MR2.

## Воспроизводимость

Одинаковые seed и словарь с одинаковым содержимым и порядком слов дают одинаковый ответ.

Seed не является индексом слова. Разные seed могут выбрать одинаковое слово. Перестановка слов в словаре может изменить ответ при прежнем seed.

## Запуск и проверка

Требуется JDK 25 или новее. Отдельно устанавливать Gradle не нужно: используется Gradle Wrapper.

```bash
./gradlew run
./gradlew check
```

Запуск обязательных тестов MR1:

```bash
./gradlew test --tests 'academy.fiveletters.mandatory.mr1.*'
```

Форматирование и полная проверка перед отправкой:

```bash
./gradlew spotlessApply check
```

## Тесты

Обязательные тесты MR1 проверяют:

- наличие минимум 50 слов в загруженном словаре;
- длину каждого слова;
- отклонение пустого словаря;
- одинаковый ответ при одинаковом seed;
- наличие разных ответов при переборе фиксированного диапазона seed.

Дополнительные тесты проверяют неправильную длину слова, латинские буквы, некорректные аргументы сессии и её начальное состояние.

Тесты MR2 и MR3 пока отключены через `@Disabled`. Пропущенные тесты не подтверждают выполнение требований.
