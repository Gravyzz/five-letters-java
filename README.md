# Проект 1. «5 букв»

Учебный проект консольной игры в духе Wordle: игрок должен угадать слово из пяти русских букв за ограниченное количество попыток.

## Текущий статус

Реализованы MR1 и MR2:

- загрузка и валидация словаря;
- воспроизводимый выбор ответа по `seed`;
- игровая сессия с историей попыток и статусом;
- проверка введённого слова;
- определение статуса каждой буквы;
- корректная обработка повторяющихся букв;
- переходы в состояния победы и поражения;
- запрет попыток после завершения игры.

Консольный интерфейс пока не реализован. Команда `run` запускает заглушку - это будет сделано в MR3.

## Основные классы

Классы игровой логики находятся в пакете `academy.fiveletters.game`.

- `WordDictionary` проверяет входной список и хранит его неизменяемую копию. Словарь не может быть пустым или `null`. Каждое слово должно состоять ровно из пяти строчных русских букв без `ё`.
- `DictionaryLoader` загружает встроенный ресурс `/dictionary.txt` в UTF-8, пропускает пустые строки и комментарии.
- `GameFactory` выбирает ответ из словаря с помощью `Random(seed)` и создаёт новую игровую сессию.
- `GameSession` хранит ответ, максимальное количество попыток, число использованных попыток, историю и текущий статус игры.
- `GameRules` проверяет введённое слово, создаёт результат попытки и передаёт его игровой сессии.
- `LetterMatcher` определяет статус каждой буквы попытки относительно ответа.
- `GuessResult` хранит нормализованное слово попытки и неизменяемый список статусов его букв.
- `LetterStatus` содержит состояния `CORRECT`, `PRESENT` и `ABSENT`.
- `GameStatus` содержит состояния `IN_PROGRESS`, `WIN` и `LOSE`.
- `GameConfig` хранит общую длину игрового слова.

## Обработка попытки

При вводе слова выполняются следующие действия:

1. Проверяется, что игровая сессия ещё не завершена.
2. Слово переводится в нижний регистр.
3. Проверяется длина слова и допустимость его символов.
4. Проверяется наличие слова в словаре.
5. Для каждой буквы определяется её статус.
6. Попытка добавляется в историю, а счётчик увеличивается.
7. При полном совпадении устанавливается статус `WIN`.
8. После последней неудачной попытки устанавливается статус `LOSE`.

Некорректный ввод вызывает исключение и не изменяет состояние игровой сессии.

## Проверка букв

Статусы букв вычисляются в два прохода.

Сначала отмечаются буквы, стоящие на правильных позициях. Затем для остальных букв выполняется поиск среди ещё не использованных вхождений ответа.

Каждое вхождение буквы ответа может быть использовано только один раз. Благодаря этому повторяющиеся буквы не получают лишний статус `PRESENT`.

## Воспроизводимость

Одинаковые `seed` и словарь с одинаковым содержимым и порядком слов дают одинаковый ответ.

`Seed` не является индексом слова. Разные значения `seed` могут выбрать одинаковое слово. Изменение порядка слов в словаре может изменить выбранный ответ.

## Запуск и проверка

Требуется JDK 25 или новее. Отдельно устанавливать Gradle не нужно: используется Gradle Wrapper.

```bash
./gradlew run
./gradlew check
```

Запуск обязательных тестов MR2:

```bash
./gradlew test --tests 'academy.fiveletters.mandatory.mr2.*'
```

Форматирование и полная проверка перед отправкой:

```bash
./gradlew spotlessApply check
```

Последняя локальная проверка:

- всего тестовых сценариев: 42;
- прошло: 39;
- упало: 0;
- пропущено: 3.

Пропущены только заготовки обязательных тестов MR3.

## Ограничения

- Поддерживаются слова из пяти русских букв от `а` до `я` без `ё`.
- Допустимы только слова, находящиеся в загруженном словаре.
- Консольное меню и детерминированный консольный режим будут реализованы в MR3.
